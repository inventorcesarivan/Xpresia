# Xpresia — Karaoke con tiempo de evaluación elegido

Cambios de esta versión:

- Karaoke vuelve a mostrar el paso **Tiempo de evaluación**.
- Duraciones disponibles: **1, 2, 3, 4 y 5 minutos**.
- Se agregó el aviso:
  > SI la duracion de la cancion es menor al tiempo que eliges, la cancion volvera a comenzar luego de haber terminado hasta que completes la evaluacion.
- La duración elegida por el usuario es la duración real de la evaluación y **no se reemplaza por la duración de la canción**.
- Si la canción termina antes del tiempo elegido, Xpresia intenta reiniciarla desde el comienzo y continúa la evaluación hasta completar el tiempo seleccionado.
- Si la evaluación llega al tiempo seleccionado, se finaliza y se genera el resultado.
- El flujo de Canto/Karaoke queda: **Modo → Tiempo → Karaoke**.
