# Xpresia v47 — Ajustes de interfaz

- Reordenados los pasos de configuración de evaluación: **1. Modo de evaluación**, **2. Tiempo de evaluación**, seguido por música, texto y/o desafío según la habilidad.
- En el panel inicial de cada habilidad, **Evaluar habilidad** aparece primero en una fila propia.
- **Evaluar habilidad** conserva formato cuadrado y aumenta aproximadamente un 15% respecto de las otras acciones.
- **Aprender** y **Competir** permanecen como tarjetas cuadradas debajo, en dos columnas.
- Se mantienen las imágenes específicas de cada habilidad.
