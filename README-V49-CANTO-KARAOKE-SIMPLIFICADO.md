# Xpresia v49 — Canto/Karaoke simplificado

Cambios principales:

- La habilidad **Canto** del menú inicial ahora destaca **CANTO / KARAOKE**.
- En el panel de la habilidad, el botón principal dice **Evalúa tu desempeño Cantando Karaoke**.
- Para Canto se elimina el selector de **Modo libre / Modo imitación**.
- Al pulsar el paso 1 se muestran directamente **Evaluación con cámara** y **Evaluación sin cámara**.
- La configuración de Canto queda reducida a tres pasos:
  1. Cámara o sin cámara.
  2. Duración.
  3. Selección del karaoke.
- El paso pendiente tiene un efecto de **latido** para indicar al usuario qué debe hacer.
- Al completar cada paso aparece debajo **👌 Listo, paso configurado**.
- Después de completar un paso, el siguiente comienza automáticamente a latir.
- Al completar el tercer paso, el botón **COMENZAR EVALUACIÓN** queda habilitado.
- El resto de habilidades conserva su flujo de configuración existente.
