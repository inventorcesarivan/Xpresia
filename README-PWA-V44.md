# Xpresia v44 - PWA estable

Esta versión parte de la versión visual/funcional v39 sin extraer ni reemplazar la lógica principal de Xpresia.

Se incorporan únicamente los elementos PWA necesarios para conservar la instalación que funcionó en v42:
- manifest.json
- Service Worker pasante
- iconos PWA
- cartel flotante de instalación

El objetivo de v44 es conservar intactos los paneles de configuración, sus botones y la navegación VOLVER de v39.
