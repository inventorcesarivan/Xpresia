# Xpresia v23 — Acciones cuadradas por habilidad

Se actualizaron las tres opciones del panel que aparece al entrar a cada habilidad:

- Evalúa tu desempeño
- Aprende habilidades
- Compite contra otros usuarios

Cada opción ahora es una tarjeta cuadrada responsive con imagen representativa y texto superpuesto de alto contraste.

## Ruta de imágenes
Todas las imágenes están en:

`assets/imagenes/`

## Diseño
- PC: 3 tarjetas por fila.
- Móvil: 2 tarjetas por fila.
- Las tarjetas mantienen proporción cuadrada.
- La opción de evaluación conserva el efecto de latido y resaltado rojo que ya tenía Xpresia.
