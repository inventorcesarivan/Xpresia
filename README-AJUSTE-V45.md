# Xpresia v45 — ajuste fino de altura

Se conserva la v44 funcional/PWA. Este ajuste reduce aproximadamente 3 mm la altura de los paneles y del escenario de cámara/video, recortando el espacio por la parte inferior y desplazando el borde inferior hacia arriba. No se modificó la lógica de navegación, instalación PWA ni las funciones de evaluación.
