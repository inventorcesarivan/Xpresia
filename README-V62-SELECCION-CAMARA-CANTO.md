# Xpresia v62 — Selección de cámara solo en Canto/Karaoke

- Base funcional: Xpresia v60.
- Las demás habilidades quedan sin el cambio de selección de cámara de v61.
- En Canto/Karaoke, el Paso 1 sigue siendo la elección con cámara/sin cámara.
- Si el usuario elige **con cámara**, se abre un panel independiente para seleccionar una cámara disponible.
- La selección de cámara NO aparece como un paso adicional en el panel de pasos.
- Al elegir la cámara, vuelve al panel de configuración con el Paso 1 confirmado y activa el Paso 2 (Karaoke).
- Si el usuario elige sin cámara, pasa directamente al Paso 2.
- La cámara elegida se utiliza al iniciar la evaluación.
